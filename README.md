# Prácticas interactivas de metalógica

Aplicaciones web para la asignatura de Lógica (2.º del grado en Matemáticas y Filosofía, Universidad de Córdoba), basadas en M. Manzano, *Teoría de modelos*.

**Para usarlas:** https://manuelcrescencio.github.io/logica/

| Página | Contenido |
| --- | --- |
| `secuentes.html` | Taller de secuentes: deducciones comprobadas línea a línea (cap. III) |
| `coincidencia-sustitucion.html` | Teoremas de coincidencia y sustitución (II.4.1 y II.4.2) |
| `correccion.html` | Práctica del teorema de corrección (III.3) |

Cada página es un único archivo HTML, sin servidor ni dependencias externas. Las tipografías están en `fuentes/`. Para usarlas sin conexión, basta con descargar el repositorio y abrir `index.html`.

## Cómo actualizar una página

1. En la página del repositorio en GitHub, pulsa **Add file → Upload files**.
2. Arrastra el archivo nuevo con el mismo nombre (por ejemplo `secuentes.html`): sustituye al anterior.
3. Pulsa **Commit changes**. La web se actualiza sola en uno o dos minutos, y la versión anterior queda en el historial.
